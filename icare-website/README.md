# iCARE website

Open index.html in a browser to view the site. Edit index.html to update
the text, navigation, and styles. Keep the assets folder alongside it.

To run a local server, open a terminal in this folder and run:

    python3 -m http.server 8000

Open http://localhost:8000. Press Ctrl+C in the terminal to stop the server.
The site is static HTML and CSS and needs no build or package installation.
External links, including the recruitment form, require internet access.
